KALXA

Multi-feature Flask platform · Live in production

Featured Project — Backend & Platform

KALXA is a live, multi-feature platform I designed, built and operate end-to-end. It combines business profiles, event ticketing, reviews, media uploads and admin dashboards on a single Flask/PostgreSQL backend, with real payment processing and role-based access control.

Yoco & Paystack payment flows
Webhook verification & transaction checks
Unique ticket codes & scanning workflow
Multi-role access control
PostgreSQL schema & migrations
Production deploy (Render + Neon)

Engineering Notes

  • Backend: Flask + SQLAlchemy, modular blueprint structure separating public site, admin, payments and authentication.
  • Payments: Payment initiation, webhook receipt, signature/transaction verification, subscription state enforcement and access gating.
  • Data: Normalised PostgreSQL schema covering businesses, events, tickets, reviews and media; migration-managed via SQLAlchemy.
  • Deployment: Render-hosted app with Neon-managed Postgres, Cloudinary for media, custom domains and DNS managed directly.
  • Operations: Production troubleshooting of deployment, DNS and network issues; log review and reliability fixes.
